# MAVLab User Documentation

This section is for learners, instructors, operators, and evaluators using the shipped application.

User documents should:

- explain observable behavior in product language;
- avoid private filesystem paths and contributor-only commands;
- identify the MAVLab version when behavior is version-specific;
- distinguish phone-only use from QGroundControl-connected use;
- explain how to enter, observe, and leave operational states.

## Product surfaces

1. **Cockpit** — live flight state, telemetry, and control authority.
2. **Controller** — phone-sensor or manual flight input.
3. **SIM** — 3D digital-twin view driven by simulation state.
4. **Mission** — uploaded mission and progress visibility.
5. **Ops** — connectivity, settings, failures, logs, and operational tools.

Lesson and Labs code may exist internally without being active primary navigation. User documentation follows the shipped UI, not an old plan.
