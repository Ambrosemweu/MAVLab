# MAVLab Documentation Archive

This folder is for superseded plans, divergent copies, and historical documents that explain how MAVLab evolved but no longer define current behavior.

Archiving rules:

- preserve provenance and original date;
- add a header naming the current replacement;
- do not rewrite historical plans to look current;
- repair inbound links during any move;
- migrate in bounded changes after active implementation work is checkpointed.

Future candidates include old phase plans, superseded product-surface baselines, historical GCS/digital-twin guidelines, and duplicate documents under `mavlab-android/docs/`.
